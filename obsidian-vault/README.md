## 🚀 Cách sử dụng

1. Mở **Obsidian** → `Open folder as vault` → chọn thư mục `obsidian-vault`
2. Bắt đầu từ file [[00-MOC]] (Map of Content)
3. Sử dụng **Graph View** (`Ctrl+G`) để xem mạng lưới liên kết giữa các note
