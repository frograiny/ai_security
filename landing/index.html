Tích hợp trong 60 giây

Chỉ cần import và gọi protect(app) trên Flask app của bạn:

from flask import Flask
from ai_waf_shield import AIWafShield

app = Flask(__name__)

# Khởi tạo và bảo vệ app
waf = AIWafShield()
waf.protect(app)

@app.route("/")
def hello():
    return "Hello, Secure World!"
